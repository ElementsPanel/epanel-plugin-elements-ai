# epanel-plugin-elements-ai

插件内部 ID 为 `epanel-plugin-elements-ai`，符合市场要求的小写格式；显示名称为 `epanel-plugin-elements-ai`。开发目录仍为 `external/epanel-plugin-elements-ai`，发布命令为 `npm run publish-plugin -- epanel-plugin-elements-ai`（参数是目录名）。

点击页眉星光按钮（悬停提示「EPanel AI」），在右侧侧栏与 AI 对话，查看实例状态、修改设置、启停实例。管理员还可创建实例。

模型选择左侧可切换操作权限，初始为「默认权限」：查询和普通启停可直接执行，修改实例配置、创建实例、写入或删除文件、下载或安装需在工具消息下查看参数并选择「允许本次」或「拒绝」。确认只授权当前账号的这一次操作，拒绝不会执行；停止、断开连接、任务超时或插件卸载会使待确认操作失效。选择「完全操作」后跳过敏感操作确认，两种模式都保留账号原有的实例与文件管理权限。权限模式在本次任务开始时固定，退出账号后恢复默认，不从历史对话恢复。

对话支持 Markdown 标题、列表、表格、链接和代码块，回复以流式逐段显示，工具操作结果也会实时追加。可点击「停止生成」中断后续生成，已完成的操作记录会保留。

模型连接中断、超时、限流或服务端暂时故障时，会在首次请求后最多重连 5 次，依次等待 1、2、4、8、16 秒。侧栏显示重试次数，停止生成会立即取消重试。重试只重新请求当前模型回复，并替换这次未完成的文本和工具预览，已完成的面板操作及其记录不会重做。密钥无效、参数错误、权限变化或手动取消不重试。

侧栏顶部的历史按钮显示当前账号最近 50 段对话，点击即可恢复消息和模型继续聊天。历史保存在面板存储中，刷新或重启后仍可使用；模型被删除或接口发生变化时，原对话只供查看。账号权限范围变化后，对应的旧历史会隐藏。

侧栏右上角的设置页面内提供「我的模型」，以名称列表显示，右侧可编辑或删除；添加和编辑均在弹窗中完成，保存后更新列表，取消不保存。填写显示名称、支持流式工具调用的模型名称、完整 Chat Completions 接口地址（包含 `/chat/completions`）及 API 密钥。个人模型仅对当前账户可见，密钥不回显。聊天输入框下方的下拉框可选择个人模型或管理员预设，切换模型会开始新对话。

插件配置页通过紧凑列表维护共享预设模型：左侧为名称，右侧可编辑或删除；新增和编辑均在弹窗中进行，确认后更新列表，再保存配置，旧版本的单模型配置会迁移为一个预设。管理员可将本地模型添加为预设；普通用户自填的模型地址须为公网 HTTP(S) 地址。

两处模型编辑弹窗都可设置思考模式和强度。默认「跟随服务默认值」不发送思考参数，保留旧模型的请求行为；「启用」发送所选的 `reasoning_effort`（低 `low`、中 `medium`、高 `high`，默认中）；「关闭」发送 `reasoning_effort: "none"`。强度仅在启用时生效，切换模式会保留已选强度。具体支持取决于模型和接口；仅支持其他厂商专用思考参数的服务请使用默认模式，插件不会猜测或同时发送多种参数。参数约定参见 [OpenAI Docs 的 Chat Completions 接口说明](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。

普通用户始终只能操作自己绑定的实例，支持启动、停止、重启和修改标签、自动启动及崩溃重启设置；不能创建实例、修改启动命令或访问其他用户的实例。使用自定义模型不会改变面板权限。

聊天消息和相关实例信息会发送给配置的 AI 服务。请勿在对话中填写密码或密钥。侧栏显示工具操作结果，写操作会记录到面板操作日志。

支持列出实例目录、读取和编辑文本文件，以及新建和删除单个文件。普通用户还须具备面板文件管理权限。文件路径仅限实例目录，读取、编辑和新建内容上限为 64 KiB，沿用实例的文件编码。新建须有已存在的父目录，不覆盖已有文件；删除须由用户明确要求，不支持目录、符号链接和批量删除。AI 编辑前必须读取文件并校验内容摘要，文件有变化时需重新读取。所读取的文件内容会发送给模型并进入历史记录。

新建和删除需要同步更新 daemon 的文件插件，使其支持 `file/create-text` 和 `file/remove-file`；操作完成后才返回成功。侧栏操作结果以图标和普通文本显示，可点击展开详情。

支持读取实例最近的终端内容，默认最近 100 行、最多 16000 字符，可调整至最多 500 行、32000 字符。会清除终端控制符；内容来自节点日志快照，可能有短暂写入延迟，并非实时订阅。在实例终端页面发送消息时，会自动携带当前实例 ID，后端仍逐次校验访问权限。普通用户只能读取自己绑定实例的终端；终端内容会发送给所选模型并进入对话历史。

管理员可分步查询 MSL 镜像源的服务端、版本和构建索引，支持搜索和分页；可查询下载地址及 SHA-256 信息，或将镜像文件下载到已停止实例的根目录。下载使用自动生成的新文件名，仅下载文件，不解压、不安装、不覆盖现有服务端配置。节点文件下载器忙碌时拒绝新任务，下载提交后可查询进度；单独下载沿用文件下载服务，不宣称已校验 SHA-256。

管理员还可从选定的 MSL 服务端、版本及构建创建实例：使用节点自动分配的新目录，下载并安装文件，生成启动命令；源提供 SHA-256 时安装流程会验证摘要。Forge/NeoForge 使用官方安装器。可指定节点已有的 Java 路径，默认使用 `java`。工具返回实例 ID 和任务 ID，可查询下载及安装进度；不会自动启动服务器或接受 Minecraft EULA。失败时可读取新实例的终端诊断，不能自动重试创建。

MSL 创建需要节点启用支持 `minecraftInstall` 的实例插件。同步更新节点的实例和文件插件，以获得完成/取消状态及下载器忙碌保护；旧节点没有明确的完成标记时只显示停止状态，不推断安装成功。

支持在线搜索和下载 Minecraft 模组、插件，复用内置 `mod` 插件的 Modrinth、CurseForge、SpigotMC 来源。AI 可列出 Minecraft 版本，按关键词、游戏版本、加载器及运行环境搜索，查询项目版本、可下载文件和来源提供的依赖信息，以及查看实例已安装的模组/插件。来源兼容信息缺失时须先确认；不会自动安装依赖或删除旧版本。

节点下载器支持官方模组来源 HTTPS 连接的代理 Fake-IP 解析（`198.18.0.0/15`、`fdfe:dcba:9876::/48`），仍校验对应域名的 TLS 证书。普通下载地址、HTTP、非默认端口和其他内网地址保持公网限制，重定向会重新选择校验策略。此修复需同步更新节点 `runtime` 插件；Spigot 插件文件名还会清理版本名中的非法路径字符。

下载工具使用来源返回的项目、版本和文件标识重新解析地址，不接受模型自填下载 URL。文件进入实例 `mods` 或 `plugins` 目录，保留已有目录的大小写；混合服务端可指定目标类型。默认不覆盖同名文件，只有用户明确要求时才使用覆盖选项。节点下载器忙碌时拒绝新下载，避免打断其他任务；不会自动重启或重载实例。

普通用户的模组搜索与下载同样受文件管理开关限制，实例操作仅限自己绑定的实例。下载返回任务 ID，可查询进度和完成/失败状态，结束后的任务记录在节点内存中最多保留 30 分钟、256 条，节点重启或插件重载后失效。完成表示文件已保存，不代表已加载或已校验来源摘要；付费、禁止分发或需要登录的资源可能无法直接下载。请同步更新节点的 `mod` 与 `runtime` 插件并重新连接节点，下载依赖 `modInstallTasks` 能力。

普通的「创建实例」工具仍只创建配置，不安装服务端文件。插件未提供删除实例、目录删除、任意终端命令或用户管理工具。

每段对话保留最近 6 轮模型上下文及最多 160 条显示记录，较大的内容会进一步裁剪。模型错误或连接中断时，操作可能已经执行，请先检查实例或文件状态再重试。

每次发送消息不再限制模型请求轮数或工具调用总次数；按工具名称分别累计请求次数，同一工具达到 20 次后结束本轮。不同参数、失败请求和重复调用 ID 均计数，中间调用其他工具不清零；第 20 次请求处理后，同批次剩余调用会取消并保留结果记录。发送新消息后重新计数。权限校验、重复写操作保护、超时和手动停止仍然生效。

侧栏齿轮打开独立的聊天设置，可调整 Enter 发送，并管理个人模型。自动滚动、Markdown 渲染和文件 diff 显示始终启用。设置按账户保存；关闭 Enter 发送后可用 Ctrl+Enter 或 ⌘+Enter 发送。管理员可通过「保存设置」右侧的按钮前往该插件的配置页。
